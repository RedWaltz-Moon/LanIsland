# 澜岛 · LanIsland

Windows 11 桌面灵动岛，让日常，轻轻浮现。

将音乐、阅读、专注、待办和实用工具放在任务栏附近，轻点胶囊即可展开。支持玻璃风格的配置界面、自由配色和自定义角色主题，无需账号，数据保存在本机。

本仓库用于版本下载、使用说明和问题反馈。当前发布版本为 **1.0.0**，适用于 **Windows 11 x64**。

## 下载

进入本仓库的 **Releases**，打开 **v1.0.0**，按需下载以下文件：

| 发行形式 | 文件 | 使用方式 |
| --- | --- | --- |
| 安装版 | `LanIsland-Setup-1.0.0-win-x64.exe` | 运行安装器，选择安装位置与快捷方式 |
| 便携版 | `LanIsland-1.0.0-win-x64-portable.zip` | 完整解压后运行 `LanIsland.exe` |

每个发行文件均附同名 `.sha256` 校验文件，用于核对下载完整性。安装包与便携包包含所需运行时、本地模型和离线文档转换引擎，无需另装 .NET 或 Python。请保留完整程序目录。

## 外观与主题

- 深浅模式、页面透明度、自由配色、胶囊尺寸与位置可调，支持手动拖动定位。
- 新配置默认深色，页面透明度为 60%；胶囊与展开面保持实色。
- 连续展开、轻按反馈与水波启动过场，支持减少动画。
- 主题工坊支持角色、背景、徽记、纹样和角饰的组合，提供取色、取景、抠图及实时预览。
- 支持 `.lan-theme` 本地导入与导出。AI 制作助手提供可复制提示词，由用户选择外部工具制作后导入。
- 发行包不预装角色主题，可自行制作或导入作品。

## 日常功能

| 功能 | 说明 |
| --- | --- |
| 音乐与媒体 | 手动选择播放器，歌名与歌手整体滚动；播放控制和进度调整按媒体接口能力提供 |
| 小说阅读 | 导入本地 TXT 小说，保存阅读位置 |
| 专注计时 | 鼠标滚轮选择 1–90 分钟，默认 30 分钟，支持暂停与继续 |
| 闹钟提醒 | 小时、分钟滚轮选时，支持重复提醒与柔和连续提示音 |
| 待办便签 | 添加、编辑、保存与完成任务 |
| 临时剪贴板 | 按需开启，记录新复制的文本，最多 20 条；退出或关闭模块即清空 |
| 文件暂存 | 拖入保留引用，主动收纳后随程序目录携带；单文件最多 256 MiB，原文件保留 |
| 格式转换 | 图片互转、图片转 PDF、多图合并 PDF、PDF 按页转图片，以及 Office、TXT、Markdown 等文档转 PDF |
| 系统状态 | 主输出音量、电源、CPU 与物理内存占用 |
| 摄像头预览 | 在独立窗口内选择设备、开始或停止预览，不录音、不保存画面 |

## 开始使用

### 安装版

1. 运行 `LanIsland-Setup-1.0.0-win-x64.exe`。
2. 选择当前用户可写的安装位置，按需选择快捷方式。开机启动默认关闭。
3. 安装完成后启动澜岛，在配置中心调整外观并管理功能。

### 便携版

1. 将便携 ZIP 完整解压到可写目录或 U 盘。
2. 运行解压后 `LanIsland` 文件夹内的 `LanIsland.exe`。
3. 退出程序后，可携带整个 `LanIsland` 文件夹及已收纳的数据。

左键点击胶囊展开当前活动，双击托盘图标打开配置。关闭配置窗口会将其隐藏；完全退出请使用托盘菜单中的“退出澜岛”。

## 本地数据

配置、主题、导入书籍、已收纳文件与工坊记录集中存放在程序目录的 `Data/` 中。

在“功能管理 → 本地数据”中，可手动导出或导入 `.lan-backup`。完整导入会替换当前数据并重新启动程序；外部暂存文件需要先收纳，才能随备份携带。

安装版支持使用新版 Setup 覆盖更新，保留个人数据。卸载默认保留 `Data/` 和 `DataRecovery/`，可主动勾选清除个人数据。便携版按下载版本独立使用，数据迁移通过手动导出、导入完成。

## 兼容说明

- 音乐识别、播放控制、进度和切曲取决于播放器提供的 Windows 媒体接口；未提供的能力会停用。
- 摄像头设备选择只作用于澜岛内的预览，其他软件需自行选择设备。
- 文档排版与转换结果会受到原文件、字体及离线引擎支持范围的影响，原文件保留。
- 闹钟需要保持澜岛运行，不支持关机或睡眠唤醒。
- 部分开始菜单及任务栏交互场景下，岛体可能临时隐藏。
